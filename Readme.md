\# Diffusion-Pretrained Dynamic Brain Networks for Neurological Disorder ClassificationThis repository provides the official implementation of DPNet, a diffusion-based framework for dynamic brain network analysis using resting-state fMRI data.\## OverviewModeling dynamic brain networks is challenging due to severe noise in BOLD signals, inter-subject variability, and unstable functional connectivity patterns. DPNet addresses these issues by integrating diffusion-based denoising with adaptive brain connectivity modeling, enabling the learning of robust dynamic brain representations for neurological disorder classification.\## Environment\- Python >= 3.8\- PyTorch >= 1.12\- CUDA >= 11.7Install dependencies:```bashpip install -r requirements.txtData PreparationExperiments are conducted on the ADNI and ABIDE datasets.Each dataset should be preprocessed and stored in .npy format with the following structure:timeseries: shape (N, T, ROI)corr: shape (N, ROI, ROI)label: shape (N,)Directory structure:data/\\\&nbsp;├── ADNI/\\\&nbsp;│    └── data.npy\\\&nbsp;└── ABIDE/\\\&nbsp;     └── data.npyTrainingTrain DPNet on the ADNI or ABIDE dataset:python train.py
